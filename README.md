# Calcasieu ROW Investigation

**Question:** Did private buyers acquire land ahead of Calcasieu Parish infrastructure right-of-way acquisitions between 2022 and 2026?

**Status:** Active. Dataset-first approach: build the master project list, pull parcel ownership histories (36 months before planning through ROW acquisition), then network analysis (Secretary of State filings -> people -> contributions/appointments).

Published by 337.news for accountability: the documents and working notes this investigation is built on.
